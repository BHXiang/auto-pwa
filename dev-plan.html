dsh-pwa · 分波分析代理插件开发计划

2026-08-18 状态: M1 骨架 目标: 让 DeepSeek Harness 自主完成分波分析迭代拟合

1. 目标与终止判据

命令行执行 dsh --profile headless "完成分波分析"，代理在无人工干预下完成：确认中间共振态 JP → 初始分波 → 拟合 → 判断加/删共振态 → 写笔记 → 迭代，直到达成目标。

判据值说明
pull 分布所有质量 bin 的 |pull| < 5数据-拟合残差按误差归一，无超过 5σ 的偏差 bin
ΔNLL< 10（连续 3 轮）新增共振态后 NLL 改进 < 10 ≈ 显著性 < 4.5σ（√2ΔNLL），停止添加
轮数上限待定（建议 15）防止发散
时间预算待定模型在笔记中跟踪

2. 架构：三种开发范式

范式在本项目中的角色
Agent Loop（主循环）headless 会话中模型自己迭代：读评估 → 查知识 → 决策 → 调用工具。科学判断（加什么共振态）不可预定义，交给推理
PTC（程序化工具调用）8 个 pwa_* 工具，每个封装一个完整程序，输入输出全结构化 JSON。机械链（改配置/拟合/解析）不进模型上下文
Workflow（保险丝）可选：初始化骨架（M3 后评估）；失控时切 ralph 模式（每轮新子代理 + 结构化报告）

3. PTC 工具契约

工具输入（模型给）内部执行输出（模型拿）
pwa_lookupname / jp / massRange / decayTo查 pdg.json{hits: [{id, jp, mass, width, decayModes}]}
pwa_decay_checkmother{j,p,mass} + daughter角动量+宇称守恒+质量阈值{allowedJP, candidates}
pwa_spectrumdataFile, nBins读 dat，峰值识别{peaks, bins}
pwa_edit_configop + resonance + jpGroup校验→备份→原子写→可加载验证{ok, changed[]}（非法不改文件）
pwa_run_fitround, timeoutMsGPU 锁 → 后台跑 fit.py → 等待{status, nll, logTail}
pwa_evaluateresultsDir, baselineNll解析 txt + root pull诊断 JSON（ΔNLL/边界/pull 区域/分波幅度）
pwa_iterateconfigEdit?, round复合：校验→拟合→画图→评估= evaluate 输出 + 日志摘要
pwa_noteround, nll, decision, plan写 notes/iteration-N.md + SUMMARY.md{ok, path}

4. 数据方案

  • pdg.json 静态表：schema 含 id / aliases（对应分析里的 phi1020 这类名字）/ jp / mass / width / decayModes / status（seed | pdg）。运行时只读 JSON，不依赖 Python。
  • 种子数据：从现有分析 config 提取（Jpsi2KKeta 的 R_KK/R_Keta 系列、Jpsi2omegaKsKs 的 f0/f2/K1 系列），质量宽度取自 config 的 BWR 参数。标记 status: seed，数值待权威源校准。
  • 权威数据（M2）：scripts/fetch_pdg.py 尝试 PDG 官方 Python API；不可用则回退 scikit-hep particle 包；再不行手动整理。生成后替换 seed 并置 status: pdg。
⚠ 种子数据中的质量/宽度是近似值，只用于打通逻辑与测试；权威数值以 M2 拉取为准。

5. 模型迭代流程

  • 第 0 轮：任务文本 + pwa_spectrum（看数据）+ pwa_decay_check（定 JP）→ 初始 config → pwa_iterate → 笔记 0
  • 第 N 轮：读评估 JSON + SUMMARY.md → pwa_lookup 查 pull 偏差区的候选 → 决策 → pwa_edit_config → pwa_iterate → pwa_note
  • 终止：目标达成（pull<5 且 ΔNLL<10）→ 最终笔记 + 总结输出；或轮数/预算耗尽

6. 里程碑

M1
骨架（当前）：pdg.json 种子 + pwa_lookup / pwa_decay_check 纯函数 + 单测。纯 TS，不依赖 harness。
M2
工具化：接入 @deepseek-ai/dsh-tools，8 个 pwa_* 工具注册 + fetch_pdg.py 拉权威数据 + 挂入 profile。
M3
端到端：persona + SKILL.md + 本机 headless 跑通一个分波（如 Jpsi2omegaKsKs 或 Jpsi2KKeta），记录迭代行为。
M4
加固：超时/轮数/收敛自动停；评估 workflow 骨架与 ralph 保险丝；sbatch 部署（后置）。

7. 部署形态（后置）

sbatch 一个作业 = 一个 headless dsh 会话（作业内代理直接跑拟合命令，不嵌套 sbatch）
前置条件: 计算节点有 node+dsh+插件+API key, 出口可达 LLM API（已确认可测）
当前阶段: 本机直接运行, 不涉及 sbatch
